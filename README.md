# OTLABS

Hi! My name is Tim. I'm an occupational therapist who got way too into soldering and building things, and I landed on synthesizers. I decided to share my builds and journey here.

I'm taking all my inspiration from [freemodular.org](https://freemodular.org/).

I like a little whimsy and fantasy themes. Feel free to do whatever you want with the modules.
